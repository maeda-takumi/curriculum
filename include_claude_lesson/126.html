実践課題① 「衝動買いした商品の行動経済学的理由を説明する」

フェーズ

1. 課題の目的

  • 「なぜ自分はその商品を衝動買いしたのか？」を行動経済学の視点から理解する
  • 衝動買いは失敗ではなく「心理トリガーを体感する学び」だと気づく
  • Claude・Notion・Canvaを活用して整理・見える化する練習

2. やり方のステップ

Step1. 商品を選ぶ

  • 最近衝動買いした商品を思い出す（例：コンビニスイーツ、雑誌、ガチャガチャ、セール品の服）

Step2. Claudeで分析

Claudeに入力して、行動経済学のフレームに当てはめてもらう。

Claudeが「限定品だから希少性が働いた」「疲れていたから現在志向バイアス」などの分析をしてくれる。

Step3. Notionで表にまとめる

Notionに以下の表を作ると整理しやすい。

こうすると「なぜ買ったか」が理論的に見える。

Step4. Canvaで図解（オプション）

  • Canvaで「心理トリガー」をアイコンや矢印で図解する
  • 例：「限定」→ 希少性 → 衝動買い、「安い」→ アンカリング → 衝動買い

視覚的にまとめると自分や他人に説明しやすい。

3. 実例（コンビニスイーツの場合）

  • 商品：新作チーズケーキ
  • 衝動買い理由：
    • POPに「期間限定」→ 希少性バイアス
    • 200円という価格が「安い！」と感じた → アンカリング効果
    • 疲れていて「今すぐ癒しが欲しい」 → 現在志向バイアス

まとめると「商品そのもの」より「心理効果の組み合わせ」で買ってしまったことがわかる。

4. まとめ

  • 衝動買いは「感情」ではなく「行動経済学の仕掛け」で説明できる
  • Claudeで分析 → Notionで表整理 → Canvaで図解
  • 自分の購買行動を理論で説明できると、マーケティングの理解が一段と深まる

実践課題②「コンビニの棚を見てアンカリング効果を探す」

1 課題の目的

  • 日常生活の中で「価格設定の心理トリガー（アンカリング効果）」を見抜く力を身につける
  • 「なぜこの商品を高い/安いと感じるのか？」を言語化する
  • Claudeで分析 → Notionで整理 → Canvaで可視化 の流れを体験する

2 ステップごとのやり方

Step1. コンビニの棚を観察

  • ジュース、カップ麺、スイーツなどを眺めて「なぜ高い／安いと感じたか？」をメモする

例：

  • ペットボトルお茶：500ml 120円／600ml 150円 → 600mlの方が「お得」に見える
  • カップ麺：198円の隣に298円の高級カップ麺 → 普通の198円が「安く」見える

Step2. Claudeで分析

観察メモを入力して、行動経済学の観点で整理してもらう。

例プロンプト：

コンビニの棚で、お茶500mlが120円、600mlが150円でした。

これはアンカリング効果の観点からどう説明できますか？

Claudeが「比較対象があることで600mlの方をお得に感じる仕組み」と説明してくれる。

Step3. Notionで整理する

Notionに以下の表を作ると、自分の気づきが体系化できる。

Step4. Canvaで図解（オプション）

  • Canvaで「価格比較図」を作り、矢印で「高価格 → 安く見える心理」の流れを描く
  • 見せる資料や学習ログとして残せる

3 実例（カップ麺コーナーを想定）

  • 商品：カップラーメン
  • 価格：198円、298円、398円

アンカリング効果：

  • 398円の高級商品があることで、298円が「中間で安心」と感じる
  • 本来198円でも十分だが「損したくない心理」で真ん中を選びやすい

消費者は「絶対価格」ではなく「相対的な比較」で判断している。

4 まとめ

  • アンカリング効果は比較対象を意識させることで価値を操作する手法
  • コンビニは「ちょっと高い商品」をわざと並べて、他商品を安く見せている
  • Claudeで分析 → Notionで表整理 → Canvaで図解すると理解しやすい

実践課題③「自分のSNSに希少性を取り入れた投稿を考える」

1. 課題の目的

  • 行動経済学で強力な心理トリガー「希少性」をSNS運用に応用する
  • 「今しかない」「残りわずか」などの表現が、人を動かす仕組みを理解する
  • Claudeでアイデア化 → Notionで整理 → Canvaでビジュアル化という一連の流れを体験する

2. ステップごとのやり方

Step1. 投稿テーマを決める

  • 例：副業講座／ハンドメイド商品の告知／YouTube更新告知／限定イベント案内
  • 「数量」「期間」「特典」で希少性を出す

Step2. Claudeで文章を作る

プロンプト例：

SNSで「ハンドメイドアクセサリーの販売告知」をします。

行動経済学の「希少性効果」を意識した投稿文を3パターン作ってください。

Claudeが「限定◯個」「今週末まで」「先着順」などを含んだ文を生成してくれる。

Step3. Notionで整理する

Notionに「希少性SNS投稿アイデア集」として表にまとめると便利。

Step4. Canvaで投稿デザイン

  • Canvaで「SNS投稿用テンプレート」を選ぶ
  • 「限定」「残りわずか」「今だけ」などの文字を目立たせる
  • カウントダウンや「先着アイコン」を入れると効果が上がる

見た瞬間に「急がなきゃ」と思わせるビジュアルにする。

3. 実例（金魚掬いのコツ解説）

  • テーマ：金魚掬いスキル講座
  • 希少性の要素：期間限定、人数限定
  • 投稿文例：「【必読】このポイントを押さえるだけで無限にgetできちゃう。金魚掬いスキル公開」

単なる告知よりも「だれでもできる感」が出て、行動を促せる。

4. まとめ

  • 希少性は「今しか買えない」「残りわずか」と思わせる仕掛け
  • Claudeで文案を作り、Notionで整理し、Canvaでビジュアル化する
  • 実際のSNS投稿に応用することで、マーケティング心理を実感できる
